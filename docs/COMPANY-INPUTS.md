# 公司接線資訊工作單

版本 0.4.0。請在公司內部副本填写；不要填密碼、token、真實對話或個人資料。公司內部網址與樣本存 company_local，以下以文件位置／窗口代稱即可。未取得時填「待確認」，不要猜測。

| 工作 | 公司需提供 | 填寫處 | 修改入口／完成條件 |
|---|---|---|---|
| 安裝 | 核准 Python 3.10.4 x64 含 Tk 路徑、pip 鏡像／離線政策、可信 CA 與代理設定方式 | 待確認 | setup／doctor；獨立環境與基準測試通過 |
| Chatbot 契約 | 一份成功呼叫的去識別樣本：method、header 名稱、request/response shape、SDK 方式、模型／助理識別的設定方式 | 待確認 | CompanyAssistant；合成 wire 契約与真實文字回覆分開通過 |
| Chatbot session | 對話 session 如何建立、傳遞、銷毀、逾期；兩使用者與兩對話如何隔離 | 待確認 | adapter 邊界；人工及服務證據確認上下文隔離 |
| 工具能力 | 助理是否原生執行查詢／寄信／寫入；公司能否提供純文字測試助理；測試範圍核准記錄 | 待確認 | 無能力證據前不啟動真實連線測試；Plan 預覽保持本機 |
| AD／名單 | 既有登入服務、LDAPS 規範、員工主鍵、單位／allowlist 來源、停用與逾期規則、shared device 政策 | 待確認 | CompanyIdentity + 每次 Engine／排程派發授權；允許／拒絕／停用／逾期／owner 隔離 |
| Oracle 接入 | 核准查詢服務契約或公司核准的直連治理方式；scope 身份來源、timeout／row cap | 待確認 | OracleQueries；唯讀、bind、身份範圍不由使用者輸入覆蓋 |
| GUI／Excel | 實際 Windows／縮放／字型、Excel 版本與地區格式、資料保存政策 | 待確認 | 真桌面動作與 Excel 複製逐字驗收；見 COMPANY-ACCEPTANCE |
