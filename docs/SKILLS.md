# 自建 Skill 與單助理 Plan mode

0.23.0 提供「我的 Skills」。Skill 是你保存的工作方法，不是可執行程式或工具授權。同一位助理依序規劃、搜尋及整理；這不等於不同模型獨立覆核。WebView 與 CLI 共用 SkillService、WorkflowService、LangGraph 及原排程器，Tk 備用保留舊功能。

## 第一次使用

1. 在側欄選「我的 Skills」。複製「每日市場情報」，或新增空白方法。
2. 填名稱、用途、工作指示、預期格式與必要條件。條件可用文字、是非、單選、多選。也可以明確按「用對話建立」，請助理提出草稿，再自行修改。
3. 預覽後確認保存。保存只留下方法，不會執行或啟用排程。
4. 選「使用並規劃」，選一位助理並填必要條件。真實助理須先通過旁邊的「測試 Skill 相容性」。離線示範不需金鑰。
5. 請助理規劃；有缺條件時回答問題。核對、修改步驟及其指定輸入，再預覽並按「確認執行」。一次批准整份修訂，修改後須重新確認。
6. 原處看進度、成果及限制。失敗保留已完成步驟，不自動重跑。規劃中斷可先「檢查原規劃」，僅已知請求才取回；結果不明不重送。
7. 試跑成功後，人工核對日期、來源與內容，另行同意每日傳送及台北 HH:MM。程式須開啟或留在系統匣，CLI 不執行排程器。

一般聊天仍保留。沒有背景自動選 Skill，選取或預覽不派發工作。規劃期間不開搜尋工具；只有已批准的搜尋步驟可呼叫所選助理的既有核准工具。

## 三個試用例子

**每日市場情報**：選市場「台股、美股、重大總經新聞」，來源填「官方交易所公告與具名新聞，附實際連結及日期」。檢查搜尋步驟後接整理步驟，核對結果再設定 08:00。離線模式只回合成示範，沒有即時財經資訊。

**文字工作報告**：關閉搜尋，新增文字條件「工作筆記」，指示「分成已完成、進行中、問題、需要協助；不編造負責人或期限」。輸入虛構筆記後規劃一個整理步驟。無搜尋也可測完整批准流程。

**分享給同事**：匯出 Markdown，同事匯入後是新草稿，必須重新選本機助理、預覽保存、測試與批准。舊結果、排程與授權不會跟過去。

## 相容性測試與費用

測試只在你明確同意時執行：規劃格式與整理格式最多兩次模型請求；選擇搜尋另加一次，須先核准搜尋工具。失敗停止，不自動重試。搜尋還會核對本機實際工具收據及來源入口，收到文字本身不能算通過。每次測試覆寫此助理修訂的能力證據，舊計畫綁定失效；助理 ID、endpoint 或憑證改變也須重新測試。

合成測試內容不使用個人歷史或資料庫。通過只代表格式／有限工具流程相容，不保證真實題目正確、來源可靠或零幻覺。搜尋品質及服務端權限仍由部署端核對。沒有金鑰時可用明示的離線示範；真實失敗絕不轉成示範。

## 修改、停用、刪除與保存

每次確認修改產生新修訂。已批准計畫、成果及排程保持原方法、條件與助理版本，不自動換新版本。停用或刪除前列出關聯排程，確認後一起暫停；已批准執行中的工作與歷史仍保留，若要停止工作請另按取消。重新啟用 Skill 不會自動恢復排程。刪除不是安全抹除，既有備份與遠端內容保留。

主資料庫 schema 8 保存 skills、skill_versions、skill_flows、skill_capabilities、skill_plan_requests；升級前 `.pre-v8-*.bak`，交易失敗回復。原 schema 1～7、獨立 DialogueStore 與未啟用 task_drafts 保持相容。不要用舊版 App 開啟 schema 8；回復須關閉程式並還原一致資料備份。

## Markdown 格式 v1

單一 UTF-8 `.md`，最多 64 KiB。開頭固定 `# QA agent Skill`，設定區塊如下，之後是純文字指示正文：

~~~~markdown
# QA agent Skill

```qa-skill-v1
{
  "name": "文字工作報告",
  "purpose": "整理工作筆記",
  "output_format": "已完成／進行中／問題／需要協助",
  "fields": [{"id":"notes","text":"工作筆記","type":"text","options":[]}],
  "search": false
}
```

依提供的筆記整理；未知事項明示，不編造負責人或期限。
~~~~

設定區不含 endpoint、金鑰或助理識別。未知欄位／未知格式版本拒絕；普通 Markdown 只作指示正文，其餘欄位自行補齊。Markdown 中的 shell、HTML、連結或「已批准」文字不會變成可執行功能。

名稱120字、用途1000字、指示8000字、成果格式2000字。最多12個必要條件，每題最多10選項、選項150字；文字答案4000字，合計答案10000字。工作輸入過大明示停止，不默默截斷。分享前仍請檢查你自行填入的正文是否包含私密資訊；系統不保證辨識任意文字中的秘密。

## CLI

`qa.bat skills` 列出JSON；`qa.bat` 進互動工作台。

```text
/skills
/skill <SkillID> <本機profileID>
/skill-values {"notes":"完成測試；明日確認規格"}
/reply 請整理為工作報告
/status
/preview
/approve
/result <工作ID>
/skill-schedule 08:00
```

`/skill-save {"data":{...}}` 建立，加入 id/revision 修改；`/skill-copy ID` 取得新草稿。`/skill-import 路徑.md`、`/skill-export ID 路徑.md` 僅接受你指定的單一檔案，匯出不覆蓋既有檔案。`/skill-manage ID disable|enable|delete` 需預覽確認。`/skill-probe profileID [search]` 需明確同意後才呼叫。`/skill-edit [步驟JSON]` 沿用服務驗證，最後一步必須整理。保存、批准、管理及匯出須互動終端確認，不接受管線或模型輸出代替授權。

`/skill-draft profileID 需求` 明確呼叫指定助理一次，回傳可修改的方法草稿；沒有自動保存或執行。

桌面與 CLI 不能同時開同一工作區。CLI 不自行啟動背景排程。`/skill-inspect`、`/skill-recover` 只檢查／恢復目前 Skill 的原規劃；不重送未知 POST。
