# 財經日報資料與授權

財經日報預覽只保存在本機記憶體，十分鐘後失效。明確試跑才將需求及當次台北時間送至選定的公司助理，結果全文存本機工作紀錄；不混入其他對話。每次工作獨立遠端 thread，退出 App 不刪除公司端資料。

人工核對與持續傳送同意後，才在既有 SQLite 建立每日排程，保存需求、助理連線版本及時間；不自動附上無關對話、DB 密碼或檔案。App 關閉時不執行，不保證睡眠或斷線時準時取得新聞。來源對話刪除不刪獨立日報工作／排程。

公司啟用檢查只盤點本機設定，沒有讀取金鑰。使用者另按連線檢查才從認證來源取得金鑰並向公司讀取助理 metadata；工具宣告不代表工具可用或已批准，沒有呼叫模型或 pluginapi。

# Assistants 與 checkpoint 本機資料

使用者資料目錄新增 assistant-sessions.sqlite3（遠端 thread/run ID、歷史雜湊、請求狀態與回覆快取）及 workflow-checkpoints.sqlite3（graph 游標、task/step ID、定義指紋）。不包含 API key，亦不自動上傳 LangSmith。

主画面的一般公司聊天沿用遠端 thread；建立任務每輪以歷史與目前欄位建立獨立 thread。公司 thread 不隨退出 App 刪除；遠端保留由公司政策管理，本機刪除不代表公司端刪除。

刪除進階對話時，對應本機公司回覆快取在同一刪除交易中清理；已批准的獨立流程與收據仍保留。主畫面歷史維持原有保存機制，沒有新增永久刪除入口。備份／匯出與遠端副本不受影響，不宣稱安全抹除。

checkpoint 與業務資料分檔，恢復時必須一致；還原請先關閉 App 並還原整個資料目錄，不只覆蓋單一 DB。跨檔案的突然斷電原子性不作保證，遇到不一致停止執行。


# 兩模式資料保存

兩模式對話、條件與未啟用任務保存在既有個人資料目錄內的 `dialogue-v1.sqlite3`。這是獨立資料庫，不搬移或改寫既有local-v1資料。新主畫面不讀附件、不執行草稿，也不自動轉交到進階功能；選公司助理並送出時會連線至設定端點。

切换模式／助理只重設目前對話畫面，不永久刪除先前對話。原進階『管理對話』只清原有對話資料庫，不宣稱刪除新增離線對話庫。公司需制定資料保留及刪除流程後再部署；本版沒有跨使用者權限。

WebView載入隨專案提供的本機HTML字串，不啟動資料目錄的HTTP檔案伺服器。API 金鑰保存規則不變；示範 provider 不讀金鑰，公司 provider 從既有 Profiles 讀取憑證。

# QA agent 資料使用與功能限制

本文件說明本機產品實際行為，不取代公司資安、資料分級與使用政策，也不代表公司已完成核准。

## 資料保存與金鑰

預設個人資料位置為 %LOCALAPPDATA%\UnitHelperLocal；若使用 UNITHELPER_DATA_DIR，實際位置以設定頁為準。對話、任務、查詢結果、Plan、排程與回報存於獨立 SQLite。本機資料不等於中央備份，請依單位流程保存。

公司 endpoint、助理識別與連線設定在個人設定檔；外觀和各頁操作提示的展開／收合偏好獨立存於 ui-preferences.json。舊版 onboarding 欄位保留，但不再讀取或更新，也不會觸發歡迎視窗。API key 使用 Windows 認證管理員（keyring）；設定只保留認證索引。認證管理員不可用時不改存明文。舊環境變數金鑰保留相容讀取，不自動匯入或刪除。

金鑰不應加入 SQLite、日誌、診斷報告、Git 或回報內容。不要在 agent 對話中貼上真實秘密。認證管理員不保護同一 Windows 使用者主動執行的所有程式；遵循公司帳號與裝置管理規則。

升級本機 SQLite 前先備份並以交易遷移；公司初版資料庫與舊排程需另外盤點，不會自動刪除或轉移。沒有可靠助理歸屬的舊對話保留閱讀與匯出。

## 對話刪除與保留範圍

「刪除此對話」及「管理對話」只處理這個資料目錄中的選定對話。確認後永久移除訊息、專屬 Plan、工作輸入／結果與其通知，並清除該對話的記憶體草稿及附件引用；應用沒有復原功能。未批准 Plan 不會執行；仍有背景請求或取消後尚未結束的遠端請求時，整批拒絕刪除。

原始附件、另存／匯出檔、既有備份、獨立查詢與排程、回報與表單，以及其他對話中的轉交副本仍然保留。來源刪除後，副本中的來源連結會標示「來源對話已刪除」，不連帶清除其內容。刪除不自動產生一份含原內容的新備份，也不變更公司初版資料庫。

本機刪除不會呼叫公司平台清除遠端歷史或撤回已送出內容。若需處理公司端保存資料、匯出或備份，請走公司核准流程。此功能不是磁碟安全抹除，不保證 SQLite 檔案／WAL、既有備份或其他儲存媒體上的資料不可恢復。

刪除預覽綁定所選資料的快照，10 分鐘有效；變動後需重新核對，不會悄悄刪除預覽以外的新訊息。資料庫失敗時整批回復，不把部分刪除當成功。

## 何時會送出資料

一般對話按送出會把該對話需要的內容送給所選公司助理；附件送出完整文字，不僅是畫面預覽。既有「更多選項 → 先規劃」建立本機 Plan 時不呼叫助理；新的「規劃工作」按送出會呼叫所選主代理討論需求，批准前不查詢或派發子代理。

查詢結果不會因顯示或匯出自動交給助理。「交給助理整理」及「轉交給其他助理」必須先選資料和助理，讀完預覽再確認。預覽應包含目的助理與內容範圍；不附加資料庫密碼或無關對話。一般查詢排程只查詢與通知，不自動呼叫助理整理；Groq 日報的例外須另行授權，見下方。

每段對話固定助理與連線版本；切換畫面不改變執行中工作的目的地。其他助理不自動取得歷史、草稿或附件。修改 endpoint 或 assistant ID 不會把舊 Plan 默默改送新目標。

連線測試會真的呼叫公司服務，應先確認測試助理是否能執行有副作用的原生工具。一般環境診斷不呼叫模型或資料庫。

取消只保證本機停止後續處理；已送出的資料可能已被公司服務接受，無法保證遠端撤回。公司服務的保留期限、權限、用途與副作用以公司平台政策為準，桌面應用不自行作保證。

## 待辦與文字草稿

待辦及未送出的文字草稿保存在同一使用者本機 SQLite；沒有加密資料庫或公司同步。待辦是你明確另存的文字副本，加入／修改／切換狀態不傳模型。到期日只有畫面提示，不產生通知。

草稿保存文字、用途、先規劃選擇及是否曾有附件，不保存附件路徑／內容；同次啟動的附件仍保留於記憶體，重開需重新選取。刪除對話會連同持久化草稿刪除，另存待辦及既有備份保留；待辦來源失效明示。要清除待辦副本需另外刪除。

schema 1／2／3 升級至 4 前會產生 SQLite 備份，可能包含升級前的私人內容。依公司資料保留政策管理備份；不直接降低資料庫版本。

## 示範、AI 與使用限制

示範模式的表格為合成資料，助理輸出為明確標示的固定文字或計數，不是真正 AI 分析，也不是公司營運數字。

示範助理與合成查詢在正常工作區使用，產生的歷史與工作存於目前個人資料目錄，不會因關閉程式自動清除。請先看清目前助理及查詢的示範／公司標示，再決定送出的內容。

頁首操作提示只讀取本機目前頁面狀態，不呼叫模型或資料庫，不建立工作，不填草稿，也不替使用者批准或送出。收合提示不會隱藏必要的資料送出預覽與確認步驟。

公司助理可能產生不正確、過時或缺少依據的回覆。請核對資料來源、查詢條件與時間；影響工作決策的內容須由人確認。程式不承諾回答永遠正確，也不代替公司核准流程。

本版沒有正式 AD／Oracle 接線、中央協作、無界限多 agent 自主分工、持續 Goal、遠端更新、郵件擷取、OCR、Office 原檔排版或多文件處理。正式能力與實測狀態以公司接手文件為準。

## 選用 Groq 外部試用

只有 start-trial.bat／--groq-trial 入口會讀取專案 .env 的 GROQ_API_KEY，送往固定 Groq 官方 HTTPS 端點；公司入口不讀此檔。依使用者選用方式，這份 .env 是本機明文金鑰檔，不是 Windows 認證管理員；Git 已忽略，但請勿分享整個含 .env 的專案資料夾。金鑰不寫入 SQLite、設定、診斷或回報。

試用資料保存於原資料目錄的 groq-trial 子目錄，不讀公司設定、助理清單或公司對話。每次送出會把本段對話歷史、你貼上或確認附加／轉交的文字傳到 Groq；請使用虛構或可公開資料。查看畫面、建立待辦、Plan 預覽、草稿保存及一般查詢排程不會自動傳給 Groq。設定中的測試連線會傳一筆合成短句。

外部平台的資料處理與帳戶費用依你使用的服務方案，應用不捏造平台保留政策或免費承諾。工作區刪除只清本機副本，不刪除外部平台紀錄；既有刪除／備份界線適用於試用資料。

在 Groq 試用送出查詢／自動工作需求後，已開放的結構化解析只送本次需求與合成模板說明，不送聊天歷史；已知合成查詢範例直接使用本機條件。查看卡片或本機預覽不送資料。勾選持續傳送授權並確認啟用後，每次日報會把合成查詢來源、模板、條件、時間、筆數與精確數值合計送 Groq，不含逐筆明細、其他對話或密碼。完整表格和回覆存於試用 SQLite；失敗仍保留已取得的表格。停用排程可停止後續派發；已送出的請求不能保證撤回。試用授權不能套用到公司排程或真實 Oracle 資料。

對話操作以獨立紀錄保存需求、修訂、助理綁定及工作／排程連結，不作為模型聊天歷史；完整查詢結果不會因畫面顯示而送模型。刪除對話時移除操作草稿與連結；独立查詢及自動工作保留，排程来源可標示已刪除。解析及即時工作仍在收尾時拒絕刪除，避免晚到結果重建資料。

## 排程、回報與分享

排程只在此程式開啟時運作；不是常駐中央服務。請確認需要的電腦保持開啟、程式沒有退出，並定期查看失敗通知。

問題回報目前只存本機，不自動送到管理平台，不自動附上私有資料。沒有設定維護聯絡方式時請使用單位核准管道。

分享檔案或截圖前，先核對內容是否包含員工資訊、內部網址或業務資料。診斷分享版採白名單，不包含金鑰、帳號、環境變數值、對話或資料內容；不要以自行貼上的完整錯誤本文代替分享報告。


## 多助理流程資料

schema 5 保存需求討論、計畫版本、每一步實際輸入與輸出。規劃只送本次需求、補充討論及能力目錄；不自動帶入其他聊天或附件。批准後，各子代理可自動取得計畫列出的前置輸出，不需每次手動轉交。查詢目前只傳合計／條件／資料時間等 metadata，逐筆表格留本機。啟用排程另外要求持續資料傳送授權，綁定固定計畫與助理版本。

刪除來源對話會清除未批准流程草稿，已批准獨立流程版本、步驟成果及排程仍保留，来源标為已刪除；不撤回服務端資料。仍有規劃或子代理請求尚未結束時拒絕刪除。

公司 RAG 引用依服務實際回覆提供；沒有來源時不捏造引用。程式只核對結構化 facts，不能保證自然語言中所有說法正確。覆核助理不等同人工核准或正確性保證。助理原生工具能力必須在公司環境驗證；本版不啟用寫入、寄信、生圖或任意程式工具。
