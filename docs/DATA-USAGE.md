# QA agent 資料使用與功能限制

本文件說明本機產品實際行為，不取代公司資安、資料分級與使用政策，也不代表公司已完成核准。

## 資料保存與金鑰

預設個人資料位置為 %LOCALAPPDATA%\UnitHelperLocal；若使用 UNITHELPER_DATA_DIR，實際位置以設定頁為準。對話、任務、查詢結果、Plan、排程與回報存於獨立 SQLite。本機資料不等於中央備份，請依單位流程保存。

公司 endpoint、助理識別與連線設定在個人設定檔；外觀和各頁操作提示的展開／收合偏好獨立存於 ui-preferences.json。舊版 onboarding 欄位保留，但不再讀取或更新，也不會觸發歡迎視窗。API key 使用 Windows 認證管理員（keyring）；設定只保留認證索引。認證管理員不可用時不改存明文。舊環境變數金鑰保留相容讀取，不自動匯入或刪除。

金鑰不應加入 SQLite、日誌、診斷報告、Git 或回報內容。不要在 agent 對話中貼上真實秘密。認證管理員不保護同一 Windows 使用者主動執行的所有程式；遵循公司帳號與裝置管理規則。

升級本機 SQLite 前先備份並以交易遷移；公司初版資料庫與舊排程需另外盤點，不會自動刪除或轉移。沒有可靠助理歸屬的舊對話保留閱讀與匯出。

## 對話刪除與保留範圍

「刪除此對話」及「管理對話」只處理這個資料目錄中的選定對話。確認後永久移除訊息、專屬 Plan、工作輸入／結果與其通知，並清除該對話的記憶體草稿及附件引用；應用沒有復原功能。未批准 Plan 不會執行；仍有背景請求或取消後尚未結束的遠端請求時，整批拒絕刪除。

原始附件、另存／匯出檔、既有備份、獨立查詢與排程、回報與表單，以及其他對話中的轉交副本仍然保留。來源刪除後，副本中的來源連結會標示「來源對話已刪除」，不連帶清除其內容。刪除不自動產生一份含原內容的新備份，也不變更公司初版資料庫。

本機刪除不會呼叫公司平台清除遠端歷史或撤回已送出內容。若需處理公司端保存資料、匯出或備份，請走公司核准流程。此功能不是磁碟安全抹除，不保證 SQLite 檔案／WAL、既有備份或其他儲存媒體上的資料不可恢復。

刪除預覽綁定所選資料的快照，10 分鐘有效；變動後需重新核對，不會悄悄刪除預覽以外的新訊息。資料庫失敗時整批回復，不把部分刪除當成功。

## 何時會送出資料

一般對話按送出會把該對話需要的內容送給所選公司助理；附件送出完整文字，不僅是畫面預覽。先規劃模式在建立與修改 Plan 時不呼叫公司助理，批准後才執行。

查詢結果不會因顯示或匯出自動交給助理。「交給助理整理」及「轉交給其他助理」必須先選資料和助理，讀完預覽再確認。預覽應包含目的助理與內容範圍；不附加資料庫密碼或無關對話。排程只查詢與通知，不自動呼叫助理整理。

每段對話固定助理與連線版本；切換畫面不改變執行中工作的目的地。其他助理不自動取得歷史、草稿或附件。修改 endpoint 或 assistant ID 不會把舊 Plan 默默改送新目標。

連線測試會真的呼叫公司服務，應先確認測試助理是否能執行有副作用的原生工具。一般環境診斷不呼叫模型或資料庫。

取消只保證本機停止後續處理；已送出的資料可能已被公司服務接受，無法保證遠端撤回。公司服務的保留期限、權限、用途與副作用以公司平台政策為準，桌面應用不自行作保證。

## 待辦與文字草稿

待辦及未送出的文字草稿保存在同一使用者本機 SQLite；沒有加密資料庫或公司同步。待辦是你明確另存的文字副本，加入／修改／切換狀態不傳模型。到期日只有畫面提示，不產生通知。

草稿保存文字、用途、先規劃選擇及是否曾有附件，不保存附件路徑／內容；同次啟動的附件仍保留於記憶體，重開需重新選取。刪除對話會連同持久化草稿刪除，另存待辦及既有備份保留；待辦來源失效明示。要清除待辦副本需另外刪除。

schema 1／2 升級至 3 前會產生 SQLite 備份，可能包含升級前的私人內容。依公司資料保留政策管理備份；不直接降低資料庫版本。

## 示範、AI 與使用限制

示範模式的表格為合成資料，助理輸出為明確標示的固定文字或計數，不是真正 AI 分析，也不是公司營運數字。

示範助理與合成查詢在正常工作區使用，產生的歷史與工作存於目前個人資料目錄，不會因關閉程式自動清除。請先看清目前助理及查詢的示範／公司標示，再決定送出的內容。

頁首操作提示只讀取本機目前頁面狀態，不呼叫模型或資料庫，不建立工作，不填草稿，也不替使用者批准或送出。收合提示不會隱藏必要的資料送出預覽與確認步驟。

公司助理可能產生不正確、過時或缺少依據的回覆。請核對資料來源、查詢條件與時間；影響工作決策的內容須由人確認。程式不承諾回答永遠正確，也不代替公司核准流程。

本版沒有正式 AD／Oracle 接線、中央協作、多 agent 自主分工、持續 Goal、遠端更新、郵件擷取、OCR、Office 原檔排版或多文件處理。正式能力與實測狀態以公司接手文件為準。

## 選用 Groq 外部試用

只有 start-trial.bat／--groq-trial 入口會讀取專案 .env 的 GROQ_API_KEY，送往固定 Groq 官方 HTTPS 端點；公司入口不讀此檔。依使用者選用方式，這份 .env 是本機明文金鑰檔，不是 Windows 認證管理員；Git 已忽略，但請勿分享整個含 .env 的專案資料夾。金鑰不寫入 SQLite、設定、診斷或回報。

試用資料保存於原資料目錄的 groq-trial 子目錄，不讀公司設定、助理清單或公司對話。每次送出會把本段對話歷史、你貼上或確認附加／轉交的文字傳到 Groq；請使用虛構或可公開資料。查看畫面、建立待辦、Plan 預覽、草稿保存及查詢排程不會自動傳給 Groq。設定中的測試連線會傳一筆合成短句。

外部平台的資料處理與帳戶費用依你使用的服務方案，應用不捏造平台保留政策或免費承諾。工作區刪除只清本機副本，不刪除外部平台紀錄；既有刪除／備份界線適用於試用資料。

## 排程、回報與分享

排程只在此程式開啟時運作；不是常駐中央服務。請確認需要的電腦保持開啟、程式沒有退出，並定期查看失敗通知。

問題回報目前只存本機，不自動送到管理平台，不自動附上私有資料。沒有設定維護聯絡方式時請使用單位核准管道。

分享檔案或截圖前，先核對內容是否包含員工資訊、內部網址或業務資料。診斷分享版採白名單，不包含金鑰、帳號、環境變數值、對話或資料內容；不要以自行貼上的完整錯誤本文代替分享報告。
