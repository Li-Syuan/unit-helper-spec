## 0.6.0 補充人工驗收（全部待公司實測）

- 中文輸入法：微軟注音及公司慣用輸入法各測一次。組字時 Enter 選字不得送出；完成選字後再按 Enter 才送出一次；Shift+Enter 換行、Ctrl+Enter 送出；長按、連按與空白不新增工作。先規劃仍只建 Plan，須另外批准。記 Windows／IME 版本、實際結果與證據。
- 助理接線：以遮蔽秘密的成功 API 範例確認 endpoint 是 base URL 還是動作 URL、assistant ID 的確切位置、session／thread 規則及工具副作用。未確認前不改成 model 猜測；驗證不同助理與不同對話無隱含共用上下文。
- 連線修訂：建立待批准 Plan 後更改 assistant ID／endpoint，舊 Plan 必須拒絕；名稱／備註更新不換目標；停用助理不能續送。切換對話不能自動轉交草稿／附件。
- 轉交：核對目的助理、選取筆數、欄位／精度、條件與資料時間；確認前無公司請求，失敗不改原結果；公司端取得內容只含預覽資料与整理需求。
- 憑證：使用核准測試 key，確認 Windows 認證管理員保存／更換／移除，認證不可用不得明文 fallback；檢查 Git、SQLite、日志與診斷沒有 key。舊環境變數不自動匯入或刪除。
- 原地提示：啟動直接進入正常工作區，沒有歡迎彈窗或獨立體驗。八頁提示、收合／展開與本頁手冊可用；重開保持每頁偏好。示範操作存於個人歷史，提示本身不送出或批准。公司不同縮放的 1050×700 和一般視窗都看得到主要按鈕；收合不影響草稿、選取與工作。

## 0.8.0 對話清理與顯示驗收（待公司實測）

- 在核准的本機測試資料上驗證最近對話右鍵單筆、管理對話標題搜尋、多筆勾選與全選搜尋結果；改變篩選不保留隱藏選取。預覽列出正確名稱及相關紀錄數量，取消預設焦點且不刪資料，確認後重開不再出現。
- 刪除目前／最後一筆後能繼續使用，其他對話草稿與附件仍在；相關詳情及未送出轉交預覽關閉。未批准 Plan 隨刪除移除而未派發；已完成轉交副本保留並標示失效來源。
- 在公司核准、無未授權副作用的測試助理驗證執行中與取消後遠端尚未結束時整批拒絕刪除；不自動取消、不刪一半。預覽逾 10 分鐘或內容變動須重新預覽。AD 接線後補登入者對刪除資料的實際授權檢查。
- 核對獨立查詢／排程、問題回報、原始附件、匯出及備份未改動，公司端歷史沒有被清除；不得據此宣稱磁碟安全抹除或公司資料保留政策已完成。
- 記錄正式啟動器／公司打包版本的 DPI 模式、Windows 倍率、Tk scaling、實際字型及可用工作區尺寸。分別在公司設備可提供的 100%、125%、150%、200% 真實倍率下啟動，核對深淺主題、一般／最大化、長文字／表格與確認對話框；未取得的倍率標 not_tested。
- 小工作區及高倍率下可捲動到操作區，送出、取消、批准、刪除確認及關閉可達；比較同一螢幕未縮放的原始截圖，避免用圖片預覽器縮放造成的模糊代替應用問題。最大化不應改變字型點數。
- 跨不同倍率螢幕移動另記結果與限制，本版不保證即時 DPI 重排；不得用程式模擬倍率換算測試取代真實 Windows 操作。Norton 成效也保持獨立記錄，不改防毒設定。
