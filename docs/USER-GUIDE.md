# 同仁操作說明

## 第一次開啟

雙擊專案根目錄的 `start-app.bat`；也可執行 scripts/run.ps1。頁首會清楚顯示「本機示範使用者（非 AD）」、「示範助理」及「合成查詢」。預設不會傳送公司資料；接公司模式後，送出的文字／附件及勾選整理的查詢結果會傳至已設定端點。

介面從左側導覽切換各項工作；`Ctrl+N` 新增對話，`Ctrl+Enter` 送出，`Enter` 換行。勾選先規劃時，快捷鍵也只會建立計畫，不會跳過批准。

## 對話與文字

左側新增對話、切換歷史；輸入文字後送出。選「整理重點」或「改寫文字」可取得候選結果。也可用「整理／改寫引導」回答單選／多選需求。
檔案支援單一 TXT／CSV。先看預覽，再選「使用此檔案」，最後按送出；可先移除附件。CSV 不支援改寫；原始檔案不被覆蓋。

示範模式的文字不是 AI 答案；公司模式才會真的呼叫 chatbot。失敗時看工作狀態，不會悄悄回示範內容。歷史過長會拒絕，不會刪掉內容假裝完整送出；可另開對話。

## 先規劃

勾選「先規劃」後，送出只建立候選。到「計畫與任務」預覽、修改、批准或取消。修改後需重新批准。
編輯中想做其他工作，先按「退出修改」；新對話會退出原修改。取消遠端請求只能阻止本機後續處理，已送出的請求可能仍在完成，請勿立刻反覆送出。
「待回答選項」可以重開未完成表單，保存答案後回原功能繼續，不會自動執行舊動作。

## 查詢與 Excel

從查詢選單選模板，畫面依模板列出條件；標 * 的欄位必填，錯誤會就地提示。示範模式有三項查詢，填起日（含）、迄日（不含）及分類。範例：2026-09-01 至 2026-09-02 是一天。all 表示全部類別。
查詢後到「計畫與任務」選任務、「查看結果」。勾查完後整理會把這份結果送至助理；摘要失敗時仍可看原表格。

每頁 100 列。「複製全部列」包含所有頁；「複製選取列」限本頁，Ctrl／Shift 可多選，換頁會清除選取。可選是否含欄名。Excel 貼上料號、18 位編號或高精度金額前，先將目的欄設為文字。CSV 建議用資料匯入明確指定欄位型別，直接雙擊可能被 Excel 自動改值。
公式型文字會加保護前綴；遇 Tab／換行不能用 TSV 時改匯出 CSV。剪貼簿被占用時會顯示失敗，可稍後再試。

## 排程與通知

成功查詢結果按「設為排程」→ 是 → 填頻率、時間、日期方式及通知條件。先保存停用草稿，再到「我的排程」預覽未來三次與條件、確認啟用。
「每次前一日」每次查昨天；「固定原參數」每次查原條件；只有宣告日期區間的模板才可選「每次前一日」。畫面設定時區是台北；預覽／歷史時間標明 UTC。
只有程式開著才會執行，關閉後不是 Windows 背景服務。立即執行可用於驗證，不會改排定時間。停用後不再產生新排定工作；已在執行的工作如需停止，到任務頁取消。
通知會標未讀；資料非空且改變／門檻達標或執行失敗才提醒。通知與歷史結果留在本機。

## 回報與保存

問題回報填類型、標題、描述、預期結果，可先存草稿並重新讀取修改。「完成本機回報」取得 LOCAL 編號，仍未寄給維護者。沒有自動附加對話或資料，需要告知維護者時由自己依公司管道提供。
資料在 `%LOCALAPPDATA%\UnitHelperLocal`；關閉程式再備份，不能只複製正在寫入的 SQLite 主檔。不刪資料就能在重開後讀取歷史。此版沒有遠端更新入口。

## 公司人工驗收清單

在公司 Windows／實際縮放與 Excel 下走完：聊天、檔案預覽與取消、文字另存、Plan 修改／批准／取消、三查詢、全部與選取列貼到 Excel、每日／每週啟停、回報草稿重開、應用重開資料保存。
記錄 Excel 版本、欄位型別、前導零／長整數／精確小數／空值／公式文字的逐字結果。這一步尚未在公司環境執行，請勿直接勾通過。

## 電腦環境有問題時

雙擊專案根目錄 diagnose.bat。檢查完成會保存 artifacts/diagnostics/readiness.json，可依公司管道交给維護者；不會自動上傳。報告不附對話、資料、金鑰或內部網址。Python 或 .venv 尚未安裝時，依提示先建立環境。

環境通過只表示本機條件正常；公司 API／AD／Oracle 需另由公司驗收。離線安裝與公司測試工具由維護者操作，見 README 的接手準備包。
