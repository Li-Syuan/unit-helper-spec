# QA agent 0.7.0 視覺稿

直接以瀏覽器開啟 workspace.html，不需要安裝 Node、啟動伺服器或連網。上方可切換初次使用、對話、待批准、執行中及失敗，也可切換深／淺主題。其他按鈕只呈現外觀，不會真的查詢、保存、呼叫助理或執行任務。

workspace.css 使用與 Tkinter 相同的石墨灰／柔白／青藍配色及 820px 閱讀寬度；1380px 以下收起示範詳情欄。正式桌面的小視窗以獨立詳情視窗取代側欄，功能以實際 Tkinter 畫面為準。

本目錄是離線設計參考，不是應用執行介面。沒有 WebView、React、外部 CSS／字型／CDN 或公司資料；示範文字均為合成內容。原生 Tk 字型、邊框、圓角和瀏覽器會有差異，不宣稱像素完全一致。

圖示由 scripts/build-ui-icons.py 以標準函式庫產生，為本專案原創幾何線條；來源在 desktop_app/assets/ui。正式 A 品牌圖示沿用既有生成紀錄。
