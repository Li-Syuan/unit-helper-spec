## 發布限制與現場驗收

候選版可供檢視及試跑，但正式1.0仍須：

1. 在實際桌面釐清剪貼簿讀回錯誤，再完成發布檢查；不可只修改報告或跳過案例。
2. 以endpoint／ID／key完成真實兩輪啟用、至少十輪續談、兩段對話切換與重開、失敗恢復。
3. 明確啟動工作格式與搜尋測試，跑完「交辦 → 補問／Plan → 確認 → 搜尋／整理 → 人工核對 → 每日／每週排程」；未核准工具不開放。
4. 若部署使用AD，完成實際登入、拒絕及到期；再做真人不看手冊的操作旅程。
